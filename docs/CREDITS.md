# Credits and asset notes

## Project work

**Yago Phellipe Matos Lopes** — narrative implementation, Unity scene composition, cinematic sequencing, gameplay systems, and integration.

Created at **Saxion University** for the **Narrative Systems** course. The portfolio title is **The Last Groove: Zaad's Journey**.

## Imported resources

The project contains third-party resources, including these identifiable folders and assets:

| Resource | Location / role |
| --- | --- |
| IL3DN / The Illustrated Nature sample assets | Nature models, materials, and environmental resources under `Assets/IL3DN` |
| Free Stylized Skybox | Sky materials and textures; includes its own `ReadMe.txt` |
| Handpainted Grass and Ground Textures | Terrain textures |
| Character models and animation clips | Imported files under `Assets/characters`, `Assets/animations`, and `Assets/Goblins` |
| Unity Default Playables | Timeline example/playable components under `Assets/UnityTechnologies/DefaultPlayables` |
| TextMesh Pro resources | Fonts and sprites, including the supplied Liberation Sans and EmojiOne notices |

This inventory identifies resources present in the repository; it is not a claim that their artwork or animations were created by the project author. Original publisher credits and license notices remain with the corresponding assets. Exact provenance for individual character and audio files is not fully documented here.

No blanket open-source license is applied to these imported assets. Their original terms continue to apply.
